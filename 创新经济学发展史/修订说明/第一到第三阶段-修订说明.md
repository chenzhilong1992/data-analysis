## 一、转换与格式修正

1. **标题层级**：按 PDF 字号恢复为 Markdown 层级（阶段 `#`、编 `##`、小节 `###`），摘要与参考文献说明恢复为引用块，参考文献恢复为列表并保留斜体刊名/书名。
2. **跨页断段**：跨页被截断的段落已全部接合；另有 1 处因分页恰落在句号处而被拆开的段落（11.1 布什报告“它是战后‘大科学’时代……”）已合并。
3. **原 PDF 的 Markdown 渲染错误**：总论中“第一阶段（萌芽期）”“第二阶段（战后黄金时代）”“第三阶段（危机与转向）”三段，原 PDF 残留字面 `**` 符号，且加粗范围颠倒（本应加粗的“第一阶段（萌芽期）”“思想奠基”等未加粗，整段正文反被加粗）。已还原为作者原意的加粗。第三阶段 23.4 节“演化进路（第三阶段）”“内生增长进路（第四阶段）”两处同样问题一并修正。
4. **标点统一**：21.3 节至第三阶段末尾（含全文结语末段）约 370 处半角标点（`, : ; ? ( )`）改为全角；全文直引号 `"…"` 统一为中文引号“…”。参考文献中的英文引号保持不变。另补齐中文与数字/英文之间缺失的空格 9 处（如“阿罗1962”“需求拉动vs. 技术推动”“QWERTY经济学”）。
5. **系列标题**：原系列题为“**美国**创新经济学研究主题变迁”，但第一、三阶段的核心人物多为欧洲学者（熊彼特、弗里曼、多西、帕维特、伦德瓦尔、佩雷斯等），叙述实为国际学术史。现已把全系列标题改为“创新经济学研究主题变迁”，摘要中的系列名称同步修改；正文中“与美国经济发展阶段的关系”这一分析视角保持不变。
