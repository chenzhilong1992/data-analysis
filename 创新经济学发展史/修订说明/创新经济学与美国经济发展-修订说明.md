# 《创新经济学与美国经济发展》修订说明

- 原始文件：`创新经济学与美国经济发展.pdf`（16 页；正文标题为《美国创新经济学研究主题变化历程与美国经济发展阶段的深层关系》）
- 转换稿：`创新经济学发展史/原始转换/创新经济学与美国经济发展.md`（与 PDF 文字层逐字一致）
- 修正版：`创新经济学发展史/修正版/创新经济学与美国经济发展.md`

本文是系列的独立总论，篇幅约为各专论的五分之一，采用**八阶段**分期（1900–1945、1945–1965、1965–1983、1983–1995、1986–2001、2001–2013、2013–2019、2019 至今），与系列专论的六阶段分期不同。二者的对应关系见《系列总览》。修正版保留了原文的分期与结构，只修正事实错误、补充关键出处，并统一格式与译名。

## 一、转换与格式修正

1. **转换**：与其他各篇相同，用 PyMuPDF 按字号还原标题层级（总标题 `#`，阶段 `##`，小节 `###`），加粗与斜体按字体还原；去掉空白与标记后，转换稿与 PDF 文字层逐字符比对一致。
2. **引号与空格**：直引号统一为中文引号；补齐中文与英文、数字之间缺失的空格（原文全篇均未留空格），与系列其他各篇一致。
3. **列表与注释**：“理论再塑现实”一节的四条政策反馈链改为列表；文末“注”改为引用块，其中残留的 Markdown 标记“\*STS\*”改为“（STS）”。
4. **译名统一（与全系列一致）**：尼尔森→纳尔逊；提斯→蒂斯；布莱恩乔尔夫森→布林约尔松；奥托→奥特尔；特拉杰顿伯格→特拉滕伯格；霍尔廷旺格→哈尔蒂万格；施莫克勒→施穆克勒；卢文道→伦德瓦尔；列维→利维；曼纳→默南；布鲁姆→布卢姆；范雷宁→范里宁；切斯布劳→切萨布鲁夫；马里安娜→玛丽安娜。术语方面，“创造性毁灭”→“创造性破坏”，“任务导向创新政策”→“使命导向创新政策”（避免与劳动经济学的“任务框架”混淆），“工业政策”→“产业政策”，《芯片法案》《通货膨胀削减法案》→《芯片与科学法》《通胀削减法》。
5. **标题**：本文正文标题保留“美国”二字。与系列标题不同，本文的主题正是美国经济发展阶段与研究主题的关系。

## 四、未改动但请留意
