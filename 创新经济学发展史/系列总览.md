- **分期是主题性的，不是严格的年代切分。** 第三、四、五阶段在年代上相互重叠：演化—系统转向、内生增长革命与微观—经验转向在 1980—2000 年代并行展开。所标年代表示该主题成为研究重心的大致时段。
- **范围。** 本系列以美国学界与美国经济的阶段性变化为主线，但对美国研究议程影响深远的欧洲学者（熊彼特、哈耶克、弗里曼、帕维特、多西、伦德瓦尔、佩雷斯等）同样纳入讨论。
- **核心论旨。** 研究主题的演进与经济发展的阶段性特征深刻呼应：经济条件经由“问题的凸显、数据的可得、工具的成熟、思想氛围、政策需求”五重机制塑造研究议程，但并不机械地决定它——理论的具体形态始终依赖于关键研究者的原创贡献。

## 四、三条贯穿线索

1. **方法论**：历史叙事（第一阶段）→ 总量核算与福利分析（第二阶段）→ 案例、调查与演化模拟（第三阶段）→ 形式化一般均衡模型（第四阶段）→ 微观数据与准实验（第五阶段）→ 行政链接数据、因果推断与宏观—微观统一（第六阶段）。方法、数据与问题协同演进：新数据使新问题可问，新问题又推动新数据的建设。
2. **“创新”概念**：从企业家的新组合，到外生余值，到累积与系统的过程，到非竞争的思想，到可测度、分布式的对象，再到有方向、有分配后果的过程——研究对象本身被不断重新定义。
3. **政策范式的钟摆**：从无明确创新政策，到公共科学契约与市场失灵理据，到竞争力政策，到横向“框架条件”取向，再到方向性、使命导向的产业政策回归。钟摆的位置追踪着各时代的政治经济氛围。

## 七、数据附录：检验核心论旨的量化证据

本系列的核心论旨是“研究主题随经济阶段而变迁”。各专论以叙事方式论证了这一点；本附录提供两类可复核的量化证据的框架。由于本次修订所在的云环境无法访问外部数据源（OpenAlex、FRED 等均被网络策略拦截），下表中的宏观数值依据公开统计的通行结果给出**近似值**，正式引用前请按“来源”一栏核对；主题变迁的文献计量则提供了可在本地直接运行的脚本。

这些指标与六阶段的对应关系一目了然：劳动生产率的“高—低—高—低”四段，分别对应第二阶段的乐观、第三阶段的危机、第五阶段的新经济与第六阶段的大停滞；研发来源从联邦主导转向企业主导，对应线性模型与公共科学契约向企业研发与风险资本的重心转移；专利数量的激增对应第五阶段的知识产权之争；初创率与加成率的变化则直接对应第六阶段的活力与集中之辩。

### B. 主题变迁的文献计量

脚本 `数据附录/topic_trends.py` 利用 OpenAlex 开放学术数据库，统计 1950—2024 年间经济学领域中标题或摘要包含各阶段标志性关键词的文献数量，并以同年经济学文献总量归一化，输出 CSV 与折线图。运行方法（需可访问 `api.openalex.org`）：

```bash
pip install requests pandas matplotlib
python 创新经济学发展史/数据附录/topic_trends.py --email 你的邮箱
# 输出：数据附录/topic_trends_counts.csv、topic_trends_per_1000.csv、topic_trends.png
```

脚本尚未在本环境中实际运行（外部网络不可达），首次运行时如遇 OpenAlex 接口变化，可按脚本注释中的说明调整领域过滤条件。所选关键词组与预期的上升期如下；若论旨成立，各组的相对占比应在对应阶段显著上升：
